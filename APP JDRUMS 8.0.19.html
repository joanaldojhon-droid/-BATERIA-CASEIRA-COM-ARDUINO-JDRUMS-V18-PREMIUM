J-Drums Configurador

Conecte o Arduino Mega via USB com HiDuino. O Chrome usa a Web MIDI API para comunicação SysEx direta — nenhum driver adicional necessário.

Clique em "Buscar dispositivos MIDI"
ℹ️ Requisitos
  • Navegador Chrome (desktop) ou Edge
  • Arduino Mega com HiDuino instalado
  • Cabo USB conectado ao Mega
  • Firmware J-Drums v8.0.19+
Selecionar Pad
Pad A0
Básico
Note
C2
Nota MIDI enviada ao bater o pad. O nome da nota aparece ao lado.
Thresold
Sensibilidade mínima para detectar uma batida. Valores maiores exigem mais força.
ScanTime
Tempo de varredura do pico do sinal (em ms). Captura o ponto mais alto da batida antes de enviar a nota.
MaskTime
Tempo de bloqueio após uma batida (em ms). Evita double-trigger — o pad ignora novos sinais nesse período.
Retrig
Controla re-disparo durante a vibração do pad. Aut = calculado automaticamente pelo firmware. Valores de 0 a 16 definem quantos ciclos adicionais são bloqueados.
Curve
Curva de resposta de velocidade: LIN = linear, EXP = exponencial (mais dinâmica), LOG = logarítmica (mais uniforme), SGM = sigmoide, FLT = fixa (velocidade constante).
CurveF
Ajusta a forma da curva selecionada. Valores baixos suavizam, valores altos acentuam a resposta.
Anti-Crosstalk
XtakCancel
Custo de cancelamento de crosstalk. Quanto maior, mais sinais de vibração de outros pads este pad ignora.
Tipo / Saída
Type
Tipo do sensor: Piezo = pad comum, Switch = botão/pedal, HHC = controlador de chimbal, HH = chimbal, HHs = chimbal simples, YSwitch = pedal Y, Disabled = desativado.
VelMinimo
Velocidade MIDI mínima enviada. Garante que batidas leves não enviem velocity 0 (que silenciaria a nota).
Gain
Gain (Piezo): amplificação do sinal — aumenta a sensibilidade sem alterar o Thresold. CkNote (outros tipos): nota MIDI enviada ao engasgar/choke o pad.
Channel
Canal MIDI de saída (0–15, exibido como 1–16 no DAW). Canal 9 = bateria por padrão no padrão GM.
InvSensor
Normal ⚠ Alterar somente pelo menu físico (A0 › InvSensor)
Inverte a leitura do sensor. Útil quando o pedal de chimbal envia sinais invertidos.
Rimshot Só A2
Rimshot
⚠ Alterar somente pelo menu físico
Modo de detecção de rimshot: Comp = A2+A3 juntos disparam nota especial, Forc = velocity alta dispara nota especial, Des = rimshot desativado.
RishotNote
C#2
Nota MIDI enviada quando rimshot é detectado (modo Comp ou Forc).
RishotVel
Limiar de velocity para detecção de rimshot no modo Comp. Batidas acima deste valor são consideradas rimshot.
